# WidgeDesk 5.3.2

## Dock 设置页再简化

「Dock」页原来还有一段说明文字、整体大小滑杆、外框长度滑杆，以及「外框长度随内容自动调整」按钮。这些都不再需要，现在全部移除。

页面现在只剩：

- 左侧固定图标（启动台 / 此电脑 / 切换桌面图标 / 设置）
- 位置
- 水平偏移
- 垂直偏移

**外框随内容长度自动调整的行为完整保留**，它现在是固定行为，不再需要按钮去切回。

## 行为与代码一起固定

- 「整体大小」固定为 100%（图标 48 DIP），不再提供调节。
- 「外框长度」固定为 0，即始终按内容宽度自动计算。
- 加载设置时这两个字段一律归一到上述固定值；旧文件里存过的自定义尺寸会被忽略，
  避免出现「界面上没有控件，外观却仍被旧值左右」。

其余 Dock 设置（固定图标开关、位置、偏移）照常保存并立即生效。
