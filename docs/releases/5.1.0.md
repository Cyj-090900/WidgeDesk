# WidgeDesk 5.1.0

## 修复：Dock 上莫名多出一个 TextInputHost

那是 Windows 的输入法宿主（`TextInputHost.exe`），它有一个窗口**标记为可见、
实际被系统藏起来**——你从来没见过它，它也不在任务栏上。程序只判断了「可见」，
于是把它当成了一个正在运行的应用。

现在与任务栏一致：被系统遮蔽的窗口不算。

## 更新检查改走静态清单，不再受 GitHub 限流

「检查更新」原本查询 GitHub 的 API。那套接口对**匿名**请求按来源 IP 限流，
每小时 60 次——**共用出口的地方（公司、校园网、运营商 NAT）是全楼共享这 60 次**，
所以会出现「网络明明正常，却报 403」。

现在改成读仓库里的一份静态清单 `latest.json`（由发布流程在每次发版时更新）。
静态文件不走 API，没有这个限制。

**下载校验一点没放松**：清单里带着安装包的 SHA-256 与大小，下载完仍然逐字节校验；
清单里的地址还必须属于本仓库，否则拒绝。清单本身写错或被人改过，只会得到
「更新信息无效」，不会把你引到别处。

## 兼容性

- 旧版本仍可升级：它们查的是 GitHub API，那条路继续可用。
- 静态清单暂时读不到时，程序会回退到 API——两种方式都通。

功能与 5.0.1 相同，加上上面两处。
