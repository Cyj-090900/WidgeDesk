# Widge 3.0.0

**再次更名**：WidgeDesktop → Widge。

- 可执行文件与安装包改为 `Widge.exe`、`Widge-<版本>-win-x64-Setup.exe`。
- 默认安装目录改为 `%LOCALAPPDATA%\Programs\Widge`（原 `...\WidgeDesktop`）。
- 卸载登记标识改为 `Widge.Independent`；旧标识的安装不会被覆盖，请先卸载旧版。
- 内部命名同步：`Widge.Core`、`Widge.App`、`WidgeSettings`、`WidgeDataStore`、
  `WidgeJsonContext`，以及 `WIDGE_DOTNET`、`WIDGE_PACKAGE_STAGE` 等环境变量。
- 「检查更新」指向本仓库 Releases，资产名与新程序名一致。

功能与 2.0.0 相同，本次只做更名，未改动行为。

用户数据仍在安装目录旁的 `Data`（便携版同理），不随更名移动。由于安装目录与安装标识
都变了，3.0.0 会装到新目录，**不会自动继承旧安装的数据**：若要保留原有设置、应用库、
布局和图标缓存，把旧安装目录下的 `Data` 复制到新安装目录即可（建议先卸载旧版，再装
3.0.0，最后把 `Data` 放回去）。以后从 3.0.0 起升级则不受影响。
