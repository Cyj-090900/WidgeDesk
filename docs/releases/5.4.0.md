# WidgeDesk 5.4.0

## Dock 右侧新增托盘区：网络、音量、日期时间

Dock 的应用图标之后多了一段托盘区，用一条细分隔线隔开：

| 图标 | 显示 | 点击 | 其它操作 |
|---|---|---|---|
| 网络 | 无线 / 有线 / 离线三种形态，与系统当前连接一致 | 打开 Windows 网络设置 | — |
| 音量 | 喇叭 + 声波，静音时换成叉号 | 打开系统音量合成器 | 滚轮调音量，右键切换静音 |
| 日期时间 | `HH:mm` + `yyyy/M/d` | 打开 Windows 日期与时间设置 | 悬停显示「2026年10月23日 星期五 12:29」 |

和输入法相关的部分（中/英、输入指示器）按你的要求不包含在内。

## 为什么不直接搬系统浮层

我先实测了三条路，结果都是走不通，这也是最终形态如此的原因：

1. 向任务栏的 `TrayButton`（操作中心）和 `TrayClockWClass`（时钟）发送
   `WM_LBUTTONDOWN` / `WM_LBUTTONUP`——窗口收到了消息，但**不弹出任何浮层**。
2. 换成真实的 `SetCursorPos` + `mouse_event` 点击同样两个按钮——依然不弹。
3. 用 `ms-actioncenter:` 协议启动——系统返回成功，但界面上没有出现操作中心。

系统浮层不接受这类输入。硬凑一个"看起来像"的面板，只会做成点不动的假 UI。

所以 Dock 显示的是**真实的系统状态**（网络形态来自活动的 `NetworkInterface`，
音量来自 Core Audio 的默认播放设备），点击打开的是**系统本身能到达的去处**。

## 布局怎么安排

- 托盘区固定在应用图标**之后**，不参与应用排序、拖拽与取消固定，`PinnedItemIds` 不会出现它的痕迹。
- 它占用的宽度会从磁贴条的可用宽度里扣掉，所以 Dock 拉满屏宽时应用图标照常横向滚动，不会把托盘挤出屏幕。
- 托盘图标比应用图标小（图标边 20 DIP、按钮高 34 DIP），避免和可启动的应用争夺注意力。
- 托盘宽度按同一套尺寸常量计算，而不是读首次布局前仍为 0 的 `ActualWidth`，避免磁贴条上限算大后无人修正。
- 15 秒刷新一次。时间与连接形态不需要秒级刷新，而秒级重绘和"闲置时尽量不动"冲突。

## 容错

- 取不到音频设备：音量图标显示叉号并禁用点击，提示「没有可用的播放设备」。
- 网络服务异常：显示离线图标。
- 任一项读取抛异常：托盘整体停止刷新，Dock 本体不受影响。

## 验证

- 新增 4 个测试：托盘位于应用磁贴之后且三项都可见可用、时钟与系统时间一致、
  状态取自真实系统（无线时必须有适配器名）、静音与正常的图标互斥。
- 反向验证：临时把托盘区设为 `Collapsed`，位置断言确实失败；恢复后通过。
- 实渲染确认：Dock 上出现分隔线 + Wi-Fi + 喇叭 + `12:26 / 2026/10/23`。
- 实测读取结果：`Wireless / WLAN`、音量 `40%`、未静音，与系统托盘一致。
- Core 166/166；Dock 491 通过，10 个失败与本机基线完全一致（Windows 10 不支持系统窗口捕获）。
- 19 个工程构建通过 18 个，唯一失败是既有 `NETSDK1135`。
