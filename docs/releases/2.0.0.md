# WidgeDesktop 2.0.0

**产品更名**：GlassDesk 更名为 WidgeDesktop。程序名、安装包名、安装目录和更新源一并改变。

- 可执行文件与安装包改为 `WidgeDesktop.exe`、`WidgeDesktop-<版本>-win-x64-Setup.exe`。
- 默认安装目录改为 `%LOCALAPPDATA%\Programs\WidgeDesktop`（原 `...\GlassDesk`）。
- 卸载登记标识改为 `WidgeDesktop.Independent`；旧标识的安装不会被覆盖，请先卸载旧版。
- 「检查更新」指向本仓库 Releases，资产名与新程序名一致。

功能与 1.3.2 相同，本次只做更名，未改动行为。

用户数据仍在安装目录旁的 `Data`（便携版同理），不随更名移动。由于安装目录与安装标识
都变了，2.0.0 会装到新目录，**不会自动继承旧安装的数据**：若要保留原有设置、应用库、
布局和图标缓存，把旧安装目录下的 `Data` 复制到新安装目录即可（建议先卸载旧版，再装
2.0.0，最后把 `Data` 放回去）。以后从 2.0.0 起升级则不受影响。

公开源码：本仓库。上游来源见 SOURCE-PROVENANCE.json，采用 Apache-2.0，保留第三方版权与许可说明。
