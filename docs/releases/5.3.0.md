# WidgeDesk 5.3.0

## 新增：Dock 上的设置入口

Dock 左侧固定图标多了一个**齿轮**，点一下直接打开 WidgeDesk 设置中心，不用再去托盘里找。

它和另外三个内置图标一样：

- 固定在应用图标左侧，顺序是「启动台 → 此电脑 → 切换桌面图标 → 设置」。
- 悬停有和 Dock 其它图标相同的放大曲线。
- 在「设置 → Dock → 左侧固定图标」里可以单独关掉。

## 外观页只留液态玻璃

磨砂玻璃已经下线：**界面、渲染实现、相关测试一并删除**，不是仅仅把选项藏起来。

- 外观页不再有材质下拉框，只保留一行说明。
- `FrostedGlassRenderer`、`RenderFrostedBackdropInto` 以及过渡层里所有磨砂分支都已移除。

### 旧配置不会因此丢失

枚举值 `FrostedGlass` 作为一个**只读别名**留在 `GlassMaterialMode` 里。这样做不是保留功能，而是为了兼容：

设置文件是强类型反序列化的，删掉这个枚举值会让写着 `"FrostedGlass"` 的旧文件**解析失败**，
进而被判定成「配置损坏」——用户会莫名丢光应用库、布局和所有外观设置。

保留别名之后，旧文件照常读出，加载时由 `WidgeDeskSettings.Normalize` 归一成液态玻璃，然后照常保存。
有测试专门覆盖这条路径（`LegacyFrostedChoiceLoadsAsLiquidGlassWithoutLosingTransparency`）。
