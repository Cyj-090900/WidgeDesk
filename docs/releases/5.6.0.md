# WidgeDesk 5.6.0

## 右键新增「锁定在 Dock」：退出程序也不会消失

固定项（Dock 上的常驻图标）的右键菜单现在多了两项：

| 状态 | 菜单项 |
|---|---|
| 未锁定 | 打开 / **锁定在 Dock** / 从 Dock 移除 |
| 已锁定 | 打开 / **解锁（允许移除）** |

锁定之后：

- 应用退出，图标**仍然留在 Dock 上**。
- 重启 WidgeDesk，依然在。
- 「从 Dock 移除」不再提供——即使沿着拖出栏外那条路径也不会被移走。

解锁只是放开这个保证，**图标不会因此消失**；要移除还得再点「从 Dock 移除」。

### 锁定放在存储层，而不是菜单层

「锁定项拒绝移除」这条规则写在 `LayoutStore.UnpinFromDock` 里，而不是只把菜单项藏起来。
这样拖出栏外、以及将来任何新的移除入口都会自动受同一道保护——菜单只是它的可见部分。

锁定同时隐含固定：只写锁定集合会留下「界面看不见、却移不掉」的自相矛盾状态，
所以 `LockToDock` 会一并把条目加进固定列表。

## 后台应用也能固定

上一版引入的后台应用（通知区里的常驻程序）此前只能「打开 / 退出 / 从 Dock 移除」。
现在它们的右键菜单新增「**固定到 Dock（退出后保留）**」：

- 库里没有这条记录时，先按当前进程的映像路径造一条，再固定并锁定。
- 固定后它不再是自动项，退出应用也不会被自动收走。
- 会清掉之前「移除过」的记录，避免点了固定却看不见效果。

## 旧配置兼容

`dock-layout.json` 新增 `lockedItemIds` 字段。旧文件没有该字段时按「没有锁定项」加载，
固定列表原样保留。

## 验证

- 菜单契约实测：未锁定 `打开 | 锁定在 Dock | 从 Dock 移除`；
  锁定后 `打开 | 解锁（允许移除）`。
- 新增 5 个存储层测试：锁定隐含固定、锁定项拒绝移除、解锁后仍保留图标、
  锁定跨重启保存、写盘失败回滚、旧文件无字段仍可加载。
- 新增 3 个 Dock 测试：菜单项随锁定状态切换、固定项在应用退出后仍在、
  「固定到 Dock」会入库并锁定。
- 反向验证：注释掉 `UnpinFromDock` 的锁定保护后，两条存储测试确实失败；恢复后通过。
- Core 171/171；Dock 506 通过，6 个失败与本机基线一致（Windows 10 不支持系统窗口捕获）。
- 19 个工程构建通过 18 个，唯一失败是既有 `NETSDK1135`。
