# GlassDesk 4.0.0

**撤销更名**：恢复为 GlassDesk。

2.0.0 与 3.0.0 两次更名（GlassDesk → WidgeDesktop → Widge）已整体撤销，
程序名、安装包名、安装目录、安装标识、更新资产名与内部命名全部回到 GlassDesk。

- 可执行文件与安装包回到 `GlassDesk.exe`、`GlassDesk-<版本>-win-x64-Setup.exe`。
- 默认安装目录回到 `%LOCALAPPDATA%\Programs\GlassDesk`。
- 卸载登记标识回到 `GlassDesk.Independent`。
- 内部命名回到 `GlassDeskDataStore`、`GlassDeskSettings`、`GlassDeskJsonContext` 等，
  环境变量回到 `GLASSDESK_DOTNET`、`GLASSDESK_PACKAGE_STAGE`。
- 工程名回到 `GlassDesk.App`、`GlassDesk.Core` 等，解决方案回到 `GlassDesk.slnx`。

功能与 1.3.2 完全相同：撤销是逐字节还原，没有夹带任何行为改动。

用户数据仍在安装目录旁的 `Data`，不受影响。安装 4.0.0 会装到
`%LOCALAPPDATA%\Programs\GlassDesk`；如果你装过 2.0.0 或 3.0.0 并留下了数据，
把那个安装目录下的 `Data` 复制过来即可。

标签 v2.0.0 与 v3.0.0 保留作历史记录，不建议使用。
