# GlassDesk 4.1.1

**文档修正**：README 的许可证说明改回与 LICENSE 一致的措辞。

- 原文写的是「允许修改、非商用及闭源衍生产品」，但本项目的 LICENSE 是 Apache-2.0，
  **明确允许商用**。README 与许可证说法不一致会给使用者错误信号，现改回
  「采用 Apache License 2.0，允许修改、商用及闭源衍生产品」。

功能与 4.1.0 完全相同，本次只改文档。程序代码没有任何变化。

如果你还在 4.0.0，升到 4.1.1 会一并带来 4.1.0 的两项改进：

- 搜索结果打开即入库：在搜索里点开一个应用，它自动进启动台，下次不必再搜。
  （只收应用，文件不收录。）
- 搜索框一键清除：输入框有内容时右侧出现 ×，点一下清空。

使用设置 → 关于 → 检查更新，或下载安装包覆盖现有安装。设置、应用库、布局和图标缓存均保留。
