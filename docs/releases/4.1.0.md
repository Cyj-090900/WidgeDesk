# GlassDesk 4.1.0

- **搜索结果打开即入库**：从搜索结果里打开一个应用之后，自动把它加入应用库并放进启动台。
  下次想再打开它，直接在启动台里点就行，不必重新搜一遍。
- **搜索框加一键清除**：输入框有内容时右侧出现 ×，点一下清空；空的时候不显示。

关于「打开即入库」

这不是自动收录所有搜到的东西——只有你**真的点开**了某个应用，它才会进启动台。
用户特意搜到它、又点开它，就是「我常用它」的意思，这个时机最自然。

**文件不会自动收录**：文件多半是一次性查看，把每个打开过的文件都塞进启动台只会把它撑满。
文件仍可以通过「添加」或拖入显式加入。

写入失败不影响打开：先启动程序、后写库，入库失败最多是少一条记录，不会让程序打不开。

使用设置 → 关于 → 检查更新，或下载安装包覆盖现有安装。设置、应用库、布局和图标缓存均保留。
