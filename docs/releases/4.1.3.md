# GlassDesk 4.1.3

**修复：关掉启动台再打开时，上次的搜索内容还在。**

## 原因

每次打开启动台都会走 `PrepareToShow`，它按设置决定要不要回到第一页，但**从来没有
碰过搜索框**。搜索词只写在窗口状态里，窗口关闭时状态被清掉一部分，输入框里的文字
却留着，于是下次进来还是那串字、还是过滤后的结果。

## 修法

窗口关闭时记一个标记，下次显示时消费它：把搜索框清空，回到默认的浏览页。

标记而不是无条件清空，是因为 `ShowWithTransition` 在窗口**已经可见**时也会走到
`PrepareToShow`（从 Dock 再点一次、显示器恢复后重新显示）。那种情况属于同一次会话，
把用户正在输入的搜索词抹掉是错的。

「记住当前浏览页」这个设置不受影响：它只管停在第几页，与搜索无关。

## 顺带说明

搜索是临时意图，不适合跨会话保留——关掉再打开时，用户想看的是自己的应用，
而不是上次没搜完的那串字。如果你更希望它被记住，告诉我，可以做成设置项。

功能与 4.1.2 相同，只有这一处修复。
