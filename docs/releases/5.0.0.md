# WidgeDesk 5.0.0

**产品更名**：GlassDesk → WidgeDesk。仓库同时改名。

- 可执行文件与安装包：`WidgeDesk.exe`、`WidgeDesk-<版本>-win-x64-Setup.exe`
- 默认安装目录：`%LOCALAPPDATA%\Programs\WidgeDesk`
- 卸载登记：`WidgeDesk.Independent`
- 内部命名同步：`WidgeDesk.App`、`WidgeDesk.Core`、`WidgeDeskSettings`、
  `WidgeDeskDataStore`，以及 `WIDGEDESK_DOTNET`、`WIDGEDESK_PACKAGE_STAGE` 等环境变量
- 仓库地址：`https://github.com/Cyj-090900/WidgeDesk`（旧地址仍会重定向到新地址）

功能与 4.2.1 相同，本次只做更名。

## 已装用户能直接升级

改名会让 GitHub 把响应里的仓库名改写成新名字，而旧版本把旧仓库名编译进了更新源。
程序已认下这个历史名字，所以**在 4.2.1 上点「检查更新」就能拿到 5.0.0**，
不需要手动重装。

## 用户数据

数据仍在安装目录旁的 `Data`，不随更名移动。由于安装目录与安装标识都变了，
5.0.0 会装到新目录，**不会自动继承旧安装的数据**：若要保留设置、应用库、布局和
图标缓存，把旧安装目录下的 `Data` 复制到新安装目录即可。
