# WidgeDesk 5.3.1

## 外观页再简化：玻璃效果与透明度设为固定值

「外观」页原来还有「玻璃效果」一行说明，以及 Dock / 启动台两条透明度滑杆。这些都不再需要，现在已经移除：

页面现在只剩三项：

- 使用自定义背景色（含颜色与不透明度）
- 减少动画
- （下方）Dock 设置

**行为和代码一起固定**，不是仅仅藏起控件：

- 两条透明度滑杆与它们的事件处理已从界面和代码中删除。
- `DockGlassTransparency` / `LauncherGlassTransparency` 在加载时一律回到内置默认值
  （Dock 90%、启动台 20%）。旧文件里存过的自定义数值会被忽略，
  避免出现「界面上没有开关，但外观仍被一个看不见的值左右」。

### 旧配置不受影响

设置文件里的这两个字段仍然可以读取（不会因此报解析失败），只是加载后会被归一为默认值。
其余外观设置（自定义背景、减少动画、圆角）保持原样。

## 验证

- 更新测试：透明度不再有控件、写入自定义值后加载回默认、旧磨砂配置仍归一为液态玻璃。
- 反向验证：临时把一条透明度滑杆加回页面，对应断言确实失败；移除后通过。
- 真实渲染确认外观页只剩「使用自定义背景色 / 背景颜色 / 背景不透明度 / 减少动画」。
- InteractionAcceptance 72 项全部通过（含新增的两条断言）。
- Core 166/166；Dock 491 通过，6 个失败与本机基线一致（Windows 10 不支持系统窗口捕获）。
- 19 个工程构建通过 18 个，唯一失败是既有 `NETSDK1135`。
