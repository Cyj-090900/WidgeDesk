# GlassDesk 4.2.0

Dock 与正在运行的应用打通了。

## 新增

- **运行中的应用自动出现在 Dock 上**。从启动台打开的应用、以及本来就在运行的应用，
  都会自动加入 Dock，不必先手动固定。应用**彻底关闭**后图标自己消失。
- **右键「退出程序」**。对自动出现的图标右键即可关闭那个应用。关闭走窗口自己的
  关闭流程，因此「是否保存」这类询问会照常出现，不会丢掉未保存的内容。
- **与系统状态栏一致**。Dock 上看得到的就是 Windows 任务栏上正在运行的应用
  （有可见窗口的那些）；只缩在通知区、没有任何窗口的应用不算。

## 两条列表是分开的

自动出现的图标与你自己固定的图标**互不干扰**：

- 自动出现的图标，关掉应用就消失；你自己固定的那些，应用关了也还在。
- 从 Dock 上移除一个自动图标，只影响它自己 —— 不会碰到你的固定项。
- 已经固定的应用不会再重复出现一枚自动图标。

## 移除过的图标不会马上回来

从 Dock 上移除一个**正在运行**的应用时，程序会记住这次移除，那个图标不会立刻
被重新加回来（否则菜单看起来像点了没反应）。等它真的关掉之后这条记录自动作废，
下次再打开它时会重新出现。

## 已知行为

- 自动图标排在固定图标之后，排序拖拽只作用于固定项。
- 「退出程序」对多窗口应用会逐个窗口关闭，因此可能有多个保存询问。
- 应用响应关闭的速度由它自己决定；图标要等它真的退出后才消失。
