# WidgeDesk 5.2.0

## 新增：自定义背景色（纯色 / 可全透明）

设置中心「外观」页新增了一组开关：

- **使用自定义背景色**：开启后 Dock 与启动台不再取样桌面，直接使用你选的颜色。
- **背景颜色**：`#RRGGBB`，例如 `#1E90FF`。
- **背景不透明度**：0% 到 100%，0% 即完全透明。

不透明度为 0% 时面板上不显示任何颜色，但仍能点到图标——分层窗口按像素 alpha 做命中测试，
真 0 会让整块面板变成点击穿透，所以这里保留 1/255 的 alpha，肉眼不可见。

开启自定义背景后，程序**不再启动桌面取样**：没有辅助进程、没有持续采样，
也不受显卡或系统捕获能力影响。

## 修复：第二次打开启动台时背景变成一块灰

现象：关掉启动台再打开，玻璃背景不再显示桌面内容，而是停在一块不受控的灰（浅色主题）
或深灰（深色主题）上，重启程序也一样。

根因有两层：

1. 本机 Windows 10 上，系统的窗口捕获接口
   （`Direct3D11CaptureFramePool.CreateFreeThreaded`）直接返回 `E_INVALIDARG`。
   这条路径失败后，程序按设计退回「静态壁纸」取样。
2. 静态壁纸源把**帧的取样时间**当成了场景版本。恢复读取时会重新取样并刷新这个时间，
   而喂帧方正好在读取前推进了场景版本——于是它判定「这一帧早于恢复边界」并丢弃。
   静态壁纸只会产出这一帧，不会再有下一帧，3 秒超时后就落到了兜底纯色上。

现在场景版本只随实际场景变化推进，恢复时重新取样的帧不会再被自己的时间戳判为过期。
实测：关闭自定义背景后，连续三次开关启动台都能拿到真实桌面画面。

## 兼容性

- 设置文件为增量字段。旧版 `settings.json` 缺少这几个键时按「不使用自定义背景」处理，
  行为与 5.1.0 相同。
- 色值写坏（例如手工改成 `#FF`）会退回默认色，不会让面板变成没有颜色的黑块。
