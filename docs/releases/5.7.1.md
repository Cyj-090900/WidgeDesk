# WidgeDesk 5.7.1

## 修复：后台应用图标点了没反应

上一版把后台应用从左侧条移到右侧后台条时，漏改了两处按 id 查找磁贴的地方。
它们仍然只扫左侧那条，而自动磁贴已经不在里面了：

```csharp
var model = _models.FirstOrDefault(tile => tile.EntryId == autoId);
if (model is null) return;   // ← 就是这里静默返回
```

结果是界面上一切正常、图标也亮着，但**左键点了不启动、右键也不出菜单**——
两条路径都在同一个查找处提前返回了。

现在改为同时查两条磁贴条（右侧后台条优先）：

```csharp
private DockTileModel? FindTile(string entryId)
    => _backgroundModels.FirstOrDefault(...) ?? _models.FirstOrDefault(...);
```

## 顺带修掉一个不易察觉的问题

`SyncAutoTiles` 也还在从左侧条读自动项，因此"当前集合"恒为空，
导致每次窗口事件都被判定成"集合变了"并重建整行——图标会不停重载、闪。
现在改为从右侧后台条读取。

## 验证

- 反向验证：把 `FindTile` 改回只查左侧后，
  `BackgroundTilesAreFoundByTheSharedClickAndMenuPaths` 确实失败；恢复后通过。
- 新增 3 个测试：后台磁贴能被共用点击/右键路径找到、固定磁贴仍能解析、
  连续调和不会重建后台条。
- Core 171/171；Dock 506 通过，10 个失败为本机既有的 WGC/GPU 基线
  （Windows 10 不支持系统窗口捕获），与本次改动无关。
- 19 个工程构建通过 18 个，唯一失败是既有 `NETSDK1135`。
